## Lessons

1. **Dockerfile Basics** – Writing a minimal Dockerfile, choosing a base image, and using `.dockerignore`. *Time: 45 min* – https://docs.docker.com/engine/reference/builder/
2. **Multi‑Stage Builds** – Reducing image size by separating build and runtime stages. *Time: 30 min* – https://docs.docker.com/develop/develop-images/multistage-build/
3. **FastAPI Dockerfile** – Containerizing the API with `uvicorn` and `python‑slim` base. *Time: 45 min* – https://fastapi.tiangolo.com/deployment/docker/
4. **React Dockerfile** – Building a Vite‑based React app and serving it with `nginx`. *Time: 45 min* – https://react.dev/learn#deployment (use official docs for Vite/React)
5. **docker‑compose Overview** – Defining services, networks, and volumes. *Time: 30 min* – https://docs.docker.com/compose/
6. **PostgreSQL Service Configuration** – Setting up a persistent DB container, env vars, and healthchecks. *Time: 30 min* – https://www.postgresql.org/docs/current/runtime-config.html
7. **Environment Variables & Secrets** – Passing configuration to containers securely. *Time: 30 min* – https://docs.docker.com/engine/reference/run/#env‑variable‑substitution
8. **Testing the Compose Stack Locally** – Using `docker compose up`, checking logs, and verifying API‑frontend communication. *Time: 45 min* – https://docs.docker.com/compose/gettingstarted/
