## Lessons

- **[React Docs – Data Loading](https://react.dev/reference/react)** – Learn how to use `fetch` and `axios` within React components to retrieve data from APIs. *Purpose*: data fetching. *Time*: 45 min
- **[MDN – Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)** – Understand the basics of the Fetch API, request options, and handling responses. *Purpose*: foundational network requests. *Time*: 30 min
- **[React Docs – Controlled Components](https://react.dev/reference/react-dom/components/input)** – Guide to creating controlled form inputs in React. *Purpose*: manage form state. *Time*: 40 min
- **[React Docs – Form Validation](https://react.dev/reference/react)** – Techniques for client‑side validation, custom hooks, and displaying error messages. *Purpose*: validation patterns. *Time*: 35 min
- **[React Docs – Accessibility](https://react.dev/reference/react)** – Basics of accessible forms, labeling, and ARIA attributes. *Purpose*: ensure inclusive UI. *Time*: 30 min
- **[FastAPI Docs – Request Body](https://fastapi.tiangolo.com/tutorial/body/)** – Define POST endpoints and parse JSON bodies. *Purpose*: backend for form submission. *Time*: 35 min
- **[FastAPI Docs – CORS](https://fastapi.tiangolo.com/tutorial/cors/)** – Enable CORS for the form submission endpoint. *Purpose*: allow cross‑origin POSTs. *Time*: 20 min
- **[MDN – HTTP Status Codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status)** – Overview of success and error status codes to handle in UI. *Purpose*: response handling. *Time*: 20 min
