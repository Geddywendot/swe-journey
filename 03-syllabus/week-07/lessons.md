# Week 07 Lessons

Ordered reading and practice list. Estimated total reading time: ~6 hours.

1. FastAPI Official Tutorial: "First Steps", "Path Parameters", "Query Parameters" (~60 min) [fastapi.tiangolo.com/tutorial/first-steps/](https://fastapi.tiangolo.com/tutorial/first-steps/)
2. FastAPI Official Tutorial: "Request Body", "Declare Request Example Data", "Extra Models" (~60 min) [fastapi.tiangolo.com/tutorial/body/](https://fastapi.tiangolo.com/tutorial/body/)
3. Pydantic v2 Documentation: "Models", "Fields", "Validators", and "Serialization" (~75 min) [docs.pydantic.dev/latest/concepts/models/](https://docs.pydantic.dev/latest/concepts/models/)
4. Python Official Docs: "Asynchronous I/O (`asyncio`)" - Coroutines, Tasks, and the Event Loop (~75 min) [docs.python.org/3/library/asyncio.html](https://docs.python.org/3/library/asyncio.html)
5. FastAPI Official Tutorial: "Dependencies" - First Steps, Classes as Dependencies, Sub-dependencies (~60 min) [fastapi.tiangolo.com/tutorial/dependencies/](https://fastapi.tiangolo.com/tutorial/dependencies/)
6. FastAPI Official Tutorial: "Handling Errors", "Middleware", and "CORS" (~45 min) [fastapi.tiangolo.com/tutorial/handling-errors/](https://fastapi.tiangolo.com/tutorial/handling-errors/)
