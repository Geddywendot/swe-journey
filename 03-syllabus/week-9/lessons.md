## Lessons

1. **React Getting Started** – Overview of React basics and project setup. *Time: 45 min* – https://react.dev/learn
2. **FastAPI Introduction** – Core concepts, creating a simple API. *Time: 45 min* – https://fastapi.tiangolo.com/tutorial/
3. **CORS in FastAPI** – How to enable cross‑origin requests. *Time: 30 min* – https://fastapi.tiangolo.com/tutorial/cors/
4. **Environment Variables** – Using `.env` with `python‑dotenv` and `create‑react‑app` config. *Time: 30 min* – https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Process/env
5. **Fetching Data in React** – `fetch` API and handling JSON responses. *Time: 45 min* – https://react.dev/learn/data-fetching
6. **Error & Loading States** – UI patterns for pending and failed requests. *Time: 30 min* – https://react.dev/learn/conditional-rendering
7. **Debugging CORS Issues** – Using browser dev tools and FastAPI logs. *Time: 30 min* – https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS
8. **Deploying Locally with Docker Compose** – Spin up FastAPI, React, and PostgreSQL. *Time: 45 min* – https://docs.docker.com/compose/
