# Week 08 Lessons

Ordered reading and practice list. Estimated total reading time: ~6 hours.

1. SQLAlchemy 2.0 Unified Tutorial: "ORM Declarative Mapping", "Mapped and mapped_column" (~75 min) [docs.sqlalchemy.org/en/20/orm/quickstart.html](https://docs.sqlalchemy.org/en/20/orm/quickstart.html)
2. SQLAlchemy 2.0 Asyncio: "Using Asyncio with SQLAlchemy" - AsyncSession, select, and commits (~75 min) [docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html)
3. Alembic Documentation: "Tutorial", "Auto Generating Migrations", and "Managing Branches" (~60 min) [alembic.sqlalchemy.org/en/latest/tutorial.html](https://alembic.sqlalchemy.org/en/latest/tutorial.html)
4. OWASP Password Storage Cheat Sheet: Salting, Adaptive Hashing, and Work Factors (~45 min) [cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
5. FastAPI Official Tutorial: "Security - OAuth2 with Password (and hashing), Bearer with JWT tokens" (~75 min) [fastapi.tiangolo.com/tutorial/security/oauth2-jwt/](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/)
6. RFC 7519: "JSON Web Token (JWT)" - Claims, Signatures, and Security Best Practices (~45 min) [datatracker.ietf.org/doc/html/rfc7519](https://datatracker.ietf.org/doc/html/rfc7519)
