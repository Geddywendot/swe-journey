# Week 10 – Data Fetching, Forms & Error States

This week you’ll deepen your front‑end skills by learning reliable data fetching patterns, building controlled forms, and handling loading and error UI states. Over four days you’ll create a small CRUD interface, practice optimistic updates, and add robust error feedback. **Done when** the app can create, read, update, and delete items via the FastAPI backend, showing appropriate spinners, validation messages, and error alerts throughout.
