# Week 09 – React ↔ FastAPI Integration

**Goal**: Build a small React front‑end that talks to a FastAPI backend, configure CORS, and manage environment variables for local and production builds.

**4‑hour‑per‑day plan**
- Day 1: Scaffold the FastAPI project, define a simple JSON endpoint, and run it locally.
- Day 2: Create a React app, add a service layer that calls the FastAPI endpoint, and handle CORS errors.
- Day 3: Move secrets (API URL, token) into `.env` files for both back‑end and front‑end and verify they load correctly.
- Day 4: Refactor error handling, write a short demo, and prepare a short presentation.

**Done when**: The React UI successfully fetches data from FastAPI without CORS warnings, and all secrets are loaded from environment variables.
