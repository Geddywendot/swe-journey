## Quiz

   b) `Origin`
   c) `Accept`
   d) `Content-Type`

   b) Which request headers are allowed
   c) Which client origins may make requests

   b) `response.ok`

5. Which file format is typically used to store environment variables for FastAPI?

   b) Send a custom header like `X‑Mock‑User`

7. What is the purpose of a Docker Compose network when running React and FastAPI locally?

   b) It isolates containers from the host network
   c) It allows containers to reach each other via service names, avoiding CORS problems

   b) Disabling the submit button during a request
