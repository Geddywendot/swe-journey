# Week 11 – Testing Pyramid & End‑to‑End Basics

**Goal**: Understand the testing pyramid, write fast unit tests with Vitest, create component tests using React Testing Library, and sketch basic end‑to‑end (E2E) tests.

**4‑hour‑per‑day plan**
- Day 1: Study the testing pyramid and set up Vitest for pure unit tests.
- Day 2: Write component tests with React Testing Library, focusing on rendering and user interactions.
- Day 3: Introduce a minimal E2E framework (Cypress or Playwright) and automate a critical user flow.
- Day 4: Consolidate test suites, add CI scripts, and reflect on coverage and maintenance.

**Done when**: The project has a passing Vitest unit test suite, a React Testing Library component test suite, and at least one reliable E2E test that validates a core user journey.
