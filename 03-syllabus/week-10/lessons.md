## Lessons

1. **React Data Fetching** – Using `fetch` and `axios` with async/await. *Time: 45 min* – https://react.dev/learn/data-fetching
2. **React Forms** – Controlled components and form validation with built‑in HTML features. *Time: 45 min* – https://react.dev/learn/forms
3. **Error Boundaries** – Catching rendering errors in React. *Time: 30 min* – https://react.dev/learn/error-boundaries
4. **Loading UI Patterns** – Spinners, skeletons, and progressive UI. *Time: 30 min* – https://react.dev/learn/conditional-rendering
5. **FastAPI Request Validation** – Using Pydantic models for request bodies. *Time: 45 min* – https://fastapi.tiangolo.com/tutorial/body/
6. **FastAPI Dependency Injection** – Managing DB sessions and common utilities. *Time: 30 min* – https://fastapi.tiangolo.com/tutorial/dependencies/
7. **Testing FastAPI Endpoints** – Using `httpx` and `pytest`. *Time: 45 min* – https://fastapi.tiangolo.com/tutorial/testing/
8. **Docker Compose for Full‑Stack Development** – Adding a PostgreSQL service. *Time: 45 min* – https://docs.docker.com/compose/
