## Quiz

1. What belongs in an Architecture Decision Record (ADR)?
   a) Full source code
   b) A summary of a key architectural choice, alternatives, and consequences
   c) Test results
   d) Deployment URLs

2. Which section is essential for a README to be usable by a stranger?
   a) Project history
   b) License text
   c) Step‑by‑step setup and run instructions
   d) Personal anecdotes

3. When reviewing a partner’s pull request, a useful comment should:
   a) Point out every typo
   b) Summarize the overall design and suggest improvements
   c) List unrelated style preferences
   d) Request unrelated features

4. What is a key difference between a demo and a deployment?
   a) Demos run on local machines; deployments are publicly accessible services
   b) Deployments are slower than demos
   c) Demos use Docker, deployments do not
   d) There is no difference

5. Which of the following helps keep a feature scoped?
   a) Writing as much code as possible
   b) Defining clear user stories and acceptance criteria
   c) Ignoring tests
   d) Adding many external dependencies

6. In a README, how should you document environment variables for deployment?
   a) Hide them completely
   b) List them with descriptions and indicate how to set them securely
   c) Include actual secret values
   d) Omit any mention of them
