## Exercises

- [ ] **Silver 1** – Deliver the chosen feature (taskboard UI or API) with all unit/integration tests passing in CI.  
- [ ] **Silver 2** – Write a comprehensive README (setup, run, test, deploy) and create one ADR documenting a key architectural decision (e.g., Docker multi‑stage build).  
- [ ] **Gold** – Record a ~5 min demo video showing the feature in action, deploy the app to a public URL, and share the link.
