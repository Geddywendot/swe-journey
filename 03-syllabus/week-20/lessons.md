## Lessons

1. **GitHub Docs – Writing a README** – How to structure a README so a newcomer can set up, run, test, and deploy the project. *Time*: 30 min.  
2. **GitHub Docs – Pull Requests** – Best practices for creating clear PRs and reviewing partner code. *Time*: 20 min.  
3. **Docker Docs – Building Production Images** – Steps to create a minimal, secure Docker image for a FastAPI app. *Time*: 40 min.  
4. **Render Docs – Deploying Docker Containers** – Deploying a Dockerized FastAPI service on Render (or Fly.io) with environment variables. *Time*: 45 min.  
5. **Project’s CONTRIBUTING.md** – Repository-specific contribution workflow, CI setup, and testing guidelines. *Time*: 25 min.  
6. **Project’s README.md** – Reference for existing project structure and scripts. *Time*: 15 min.  
7. **Docker Docs – Multi‑stage Builds** – Reducing image size and build time for production. *Time*: 30 min.  
8. **Render Docs – Managing Secrets** – Securely providing API keys and DB credentials to the deployed app. *Time*: 20 min.
