## Week 20 – Capstone Feature

Goal: ship a complete feature in the taskboard app (or its API) that includes full test coverage, a Dockerfile, a CI pipeline, a public deployment link, and a README that a stranger could follow to set up, run, test, and deploy the feature. You will work about four hours each day on design, implementation, documentation, and review. **Done when** the pull request is merged, the CI pipeline passes, the Docker image builds and runs, and the deployed link is reachable.
