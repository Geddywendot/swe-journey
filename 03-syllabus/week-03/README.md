# Week 03: CLI Tooling, Automated Testing with pytest, and Project 1 Prep

**Goal:** Master command-line interface development with `argparse`/`click`, test-driven development (TDD) using `pytest`, fixtures, parameterization, and mocking.
**You are done when:** You can build robust CLI applications that adhere to POSIX exit codes, handle standard stream redirection, and are covered by automated unit and integration tests.
**Time plan (4 hrs/day):**
- Day 1–2: Lessons and concepts (about 6 hrs)
- Day 3–4: Exercises silver tasks (about 8 hrs)
- Day 5: Gate and retro (about 4 hrs)
- Lighter day: Review `00-start-here/glossary.md`, prepare partner questions

**Partner session agenda (45–60 min):**
1. Concept explain-back: Pytest fixture lifecycles, test parameterization, and POSIX exit codes.
2. Gate walk-through: Live demonstration of CLI flags, help menus, error codes, and test execution.
3. PR review: Review your `week-03/gate` Pull Request.
