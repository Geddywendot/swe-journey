# swe-journey

A structured, 20-week self-study software engineering classroom repository for one learner and one learning partner.

## Quick Start
1. Read [`00-start-here/plan-at-a-glance.md`](00-start-here/plan-at-a-glance.md).
2. Read [`00-start-here/how-to-study.md`](00-start-here/how-to-study.md).
3. Set up your development environment following [`02-tools/`](02-tools/).
4. Begin with [`03-syllabus/week-01/`](03-syllabus/week-01/).

*Note: Full curriculum details, projects, and guides will be populated across structured build batches.*
