# 20-Week Plan at a Glance

A 20-week structured roadmap from foundational engineering to production fullstack software engineering.

| Week | Title | Core Focus & Artifact |
|---|---|---|
| **Week 01** | Git Mechanics & The Unix Philosophy | Shell scripting, standard streams, Git commit tree & branching mechanics |
| **Week 02** | Idiomatic Python & Modern Types | Type annotations, standard library data structures, protocols, OOP vs functions |
| **Week 03** | CLI Tooling, Testing & First Project | `argparse`/`click`, `pytest` test-driven basics, Project 1: Log Analyzer CLI |
| **Week 04** | Web Fundamentals & HTTP Protocol | HTTP request/response cycle, DNS, DOM tree, semantics, and CSS layout |
| **Week 05** | Modern TypeScript & React Foundations | Vite, strict TypeScript, React hooks, rendering lifecycle, Project 2: Static API Page |
| **Week 06** | Relational Modeling & PostgreSQL | Relational schemas, normalization, indexes, transactions (ACID), raw SQL queries |
| **Week 07** | High-Performance APIs with FastAPI | Async/await, route handlers, Pydantic v2 validation, dependency injection |
| **Week 08** | ORM, Migrations & Authentication | SQLAlchemy 2.0 (async), Alembic migrations, password hashing, JWT, Project 3: Task API |
| **Week 09** | Fullstack Integration & Client State | Fetching with TanStack React Query, Axios, token management, error boundary |
| **Week 10** | Fullstack Features & Complex CRUD | Optimistic UI updates, filtering/pagination, forms, Project 4 (Part 1): Taskboard |
| **Week 11** | The Testing Pyramid | pytest fixtures/mocking, React Testing Library, contract testing, Project 4 (Part 2) |
| **Week 12** | Containerization with Docker | Dockerfile syntax, layers, caching, non-root users, multi-stage builds |
| **Week 13** | Multi-Container Systems | Docker Compose, internal networking, persistent volumes, environment configs |
| **Week 14** | CI/CD Automation with GitHub Actions | Automated linting, test suites, multi-job pipelines, artifact caching |
| **Week 15** | Cloud Deployment & Observability | Deploying to Render/Fly.io, managed PostgreSQL, health checks, log aggregation |
| **Week 16** | System Design: Scalability & Caching | Horizontal scaling, Redis caching patterns, load balancers, rate limiting |
| **Week 17** | Data Systems & Architecture Trade-offs | Eventual consistency, message queues, MERN comparative study (Express & Mongo) |
| **Week 18** | Track A: Applied Machine Learning | scikit-learn model training, serialization, inference API, Project 5: ML Model Service |
| **Week 19** | Track B: Application Security & Defense | OWASP Top 10, SQLi/XSS defense, bandit/pip-audit, Project 6: Security Scanner |
| **Week 20** | Capstone Delivery & Final Defense | Production release of Project 7 Capstone, architectural defense, final mock exam |
