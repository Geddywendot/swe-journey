# Week 05: Modern TypeScript & React Foundations (Project 2 Prep)

**Goal:** Master static typing with TypeScript in strict mode, Vite build tooling, React functional components, hooks (`useState`, `useEffect`), and component state lifecycles.
**You are done when:** You can build an interactive React application in strict TypeScript with zero `any` types that fetches remote data, manages loading/error states, and passes React Testing Library tests.
**Time plan (4 hrs/day):**
- Day 1–2: Lessons and concepts (about 6 hrs)
- Day 3–4: Exercises silver tasks & Project 2 (about 8 hrs)
- Day 5: Gate and retro (about 4 hrs)
- Lighter day: Review `00-start-here/glossary.md`, prepare partner questions

**Partner session agenda (45–60 min):**
1. Concept explain-back: React rendering cycle, hook rules, and TypeScript generics in React.
2. Gate walk-through: Code review and live demonstration of Project 2 (Static API Page).
3. PR review: Review your `week-05/gate` Pull Request.
