# Week 01: Git Mechanics and The Unix Philosophy

**Goal:** Master the POSIX command line, standard I/O redirection pipelines, and Git internal object architecture (blobs, trees, commits, refs).
**You are done when:** You can explain Git's internal DAG without notes, recover a detached HEAD, resolve merge conflicts manually, and construct multi-stage shell pipelines.
**Time plan (4 hrs/day):**
- Day 1–2: Lessons and concepts (about 6 hrs)
- Day 3–4: Exercises silver tasks (about 8 hrs)
- Day 5: Gate and retro (about 4 hrs)
- Lighter day: Review `00-start-here/glossary.md`, prepare partner questions

**Partner session agenda (45–60 min):**
1. Concept explain-back: Git object store & merge vs rebase.
2. Gate walk-through: Demonstrate Git conflict resolution and shell pipeline output.
3. PR review: Review your `week-01/gate` Pull Request.
