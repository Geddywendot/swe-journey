## Lessons

- **[Vitest Docs – Getting Started](https://vitest.dev/guide/)** – Set up Vitest in a Vite/React project. *Purpose*: bootstrap unit testing. *Time*: 30 min
- **[Vitest Docs – Mocking](https://vitest.dev/guide/mocking.html)** – Learn how to mock modules and functions. *Purpose*: isolate unit tests. *Time*: 25 min
- **[Testing Library Docs – Introduction](https://testing-library.com/docs/react-testing-library/intro/)** – Core principles of RTL for component testing. *Purpose*: write UI tests that focus on behavior. *Time*: 35 min
- **[Testing Library Docs – Queries](https://testing-library.com/docs/queries/about/)** – Selecting elements in a way that reflects user perspective. *Purpose*: reliable selectors. *Time*: 20 min
- **[Vitest Docs – Coverage](https://vitest.dev/guide/coverage.html)** – Generate code coverage reports. *Purpose*: assess test completeness. *Time*: 20 min
- **[FastAPI Docs – Testing](https://fastapi.tiangolo.com/tutorial/testing/)** – Use TestClient for API tests. *Purpose*: include backend API tests. *Time*: 25 min
- **[Cypress Docs – Getting Started](https://docs.cypress.io/guides/getting-started/installing-cypress)** – Install Cypress for E2E testing. *Purpose*: end‑to‑end test setup. *Time*: 30 min
- **[MDN – Asynchronous JavaScript](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Asynchronous)** – Review async/await patterns used in tests. *Purpose*: handle async test code. *Time*: 20 min
