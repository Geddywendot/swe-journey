# Week 06: Relational Data Modeling & PostgreSQL Core

**Goal:** Master relational database architecture, schema normalization (1NF–3NF), constraints, B-Tree indexing, ACID transactions, and complex SQL queries.
**You are done when:** You can design normalized schemas, analyze query execution plans with `EXPLAIN ANALYZE`, and execute multi-table transactions with ACID guarantees.
**Time plan (4 hrs/day):**
- Day 1–2: Lessons and concepts (about 6 hrs)
- Day 3–4: Exercises silver tasks (about 8 hrs)
- Day 5: Gate and retro (about 4 hrs)
- Lighter day: Review `00-start-here/glossary.md`, prepare partner questions

**Partner session agenda (45–60 min):**
1. Concept explain-back: ACID guarantees, B-tree indexing, and transaction isolation levels.
2. Gate walk-through: Demonstration of normalized schema, query plans, and transaction rollbacks.
3. PR review: Review your `week-06/gate` Pull Request.
