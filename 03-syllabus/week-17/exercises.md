## Exercises

**Silver 1**
- [ ] Sketch a component diagram for a simple CRUD app (client → API → DB) using Mermaid syntax.
- [ ] Identify at least three potential failure points and write a brief mitigation strategy for each.

**Silver 2**
- [ ] Write a 500‑word comparison essay between the MERN stack (Express + MongoDB) and the FastAPI‑Postgres stack, focusing on data modeling, scaling, and operational considerations.
- [ ] Create a slide (Markdown format) summarizing the key trade‑offs you identified.

**Gold**
- [ ] Design a high‑level system that includes a load balancer, multiple API instances, a Redis cache, and a background worker queue. Document the data flow in a Mermaid diagram.
- [ ] Draft a short (3‑minute) presentation outline that explains your design decisions and the MERN vs FastAPI comparison.
- [ ] Conduct a mock review with a partner (or yourself) and record the partner’s explanation of one design choice.
